# PizzaSalesSolution

This repository contains two .NET 8 projects for the W01 Assignment:

- **PizzaApi**: An ASP.NET Core Web API for managing a list of pizzas with CRUD operations.
- **SalesReportApp**: A C# console application that works with files and directories, including generating a sales summary report.

## How to Run

1. Restore dependencies:
   ```
   dotnet restore
   ```
2. Build the solution:
   ```
   dotnet build
   ```
3. Run the Web API:
   ```
   dotnet run --project PizzaApi
   ```
4. Run the Console App:
   ```
   dotnet run --project SalesReportApp
   ```
